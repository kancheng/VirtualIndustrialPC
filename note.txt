虛擬工控機

有存放 OK 的組圖
有存放 NG 的組圖

一台工控機裡面有 N 台工站

1 台工站裡面會產生 M 張表面影像的圖。

根據存放 OK 、 NG 的組目錄，產生虛假的產品圖像。

EX: 編碼規則為代號 202512290001S11、202512292501S43

-> 20251229
-> 0001、2501，料號
-> S11 為機台的工站1的第一張圖
-> S43 為機台的工站4的第三張圖

同時，工控機預設會有幾台工站、一台工站有幾張圖都是由一個 JSON 來控制，若預設沒有則執行前產生一個 JSON。包含 有存放 OK 的組圖的目錄路徑、有存放 NG 的組圖的目錄路徑，同時存放 OK NG 的圖裡面沒有圖片也要發出提示訊息。
最後設定今天要投多少料。
